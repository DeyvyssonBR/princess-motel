# Brand spec — Motel romântico (extraído da referência mpovajwy-image.png)

## Mood
Cinematográfico, íntimo, à luz de velas. Quarto escuro com pétalas vermelhas, neon âmbar, atmosfera de "noite inesquecível". Tom: romântico, sofisticado, sussurrado — não vulgar, não kitsch.

## Paleta (OKLch)
- `--bg`:      oklch(14% 0.015 30)    /* preto-chocolate quente, base do fundo */
- `--surface`: oklch(20% 0.020 35)    /* superfície de card sutil */
- `--fg`:      oklch(96% 0.012 80)    /* off-white champanhe */
- `--muted`:   oklch(68% 0.025 60)    /* dourado pálido para texto secundário */
- `--border`:  oklch(32% 0.025 50)    /* divisor quente */
- `--accent`:  oklch(78% 0.14 75)     /* dourado/champanhe quente (neon âmbar) */
- `--rose`:    oklch(55% 0.18 25)     /* vermelho-rosa das pétalas, acento raro */

## Tipografia
- Display script (manuscrito elegante): "Allura", "Great Vibes", "Pinyon Script", cursive — usado em UMA palavra-chave por seção (ex: "inesquecível")
- Display sans (caixa alta espaçada): "Cormorant Garamond" ou system serif — para títulos secundários com letter-spacing alto
- Body: -apple-system, "SF Pro Text", system-ui, sans-serif

## Posture
- Backgrounds escuros com vinheta radial sutil
- Botões pílula champanhe (bg quente, fg escuro), ou pílula outline dourada
- Divisores ornamentais finos (linha + diamante central) entre seções
- Ícones lineares 1px (coração, vela, chave, pétala) — nunca emoji
- Imagens com filtro/grading quente, vinheta nas bordas
- Letter-spacing generoso (0.2–0.4em) em uppercase
- Acento vermelho-rosa usado no máximo 2x por tela
- Sem gradientes coloridos chamativos; só vinhetas escuras e brilhos quentes

## Copy
- Voz: sussurrada, íntima, sugestiva sem ser explícita
- Português BR
- Frases curtas; uma palavra-chave em script por seção
